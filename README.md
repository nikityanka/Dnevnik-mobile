# Dnevnik-mobile

Мобильное приложение «Дневник» для студентов, преподавателей и заведующих отделением. Реализует просмотр расписания, журнал оценок, учёт посещаемости и управление группами. Авторизация с тремя ролями пользователей, сессия сохраняется между запусками.

## Возможности

- Авторизация с разделением ролей: студент, преподаватель, заведующий.
- Просмотр расписания занятий с фильтрацией по роли пользователя.
- Журнал оценок: просмотр, добавление и удаление столбцов, типы оценок с весами.
- Учёт посещаемости с цветовой индикацией статусов и расчётом процента.
- Управление группами и студентами для заведующего: список групп, состав, предметы, преподаватели.
- Профиль пользователя с данными из API.
- Сохранение сессии и автоматический вход при повторном запуске.

## Технологии

- Клиент: React Native 0.81, Expo SDK 54, TypeScript, React Navigation (Stack и Bottom Tabs).
- Хранение сессии: AsyncStorage с TTL.
- HTTP: axios, REST API.
- Тестирование: Jest.

## Установка и запуск

Требуется Node.js 20+ и менеджер пакетов npm.

```
npm install        # установка зависимостей
npm start          # запуск Expo Dev Tools
npm run android    # запуск на Android-эмуляторе или устройстве
npm run ios        # запуск на iOS-симуляторе
npm run web        # запуск в браузере
npm test           # запуск тестов
```

Перед запуском создайте файл `.env` с параметром `API_BASE_URL` (адрес серверного API) и при необходимости `DEBUG_MODE`.
